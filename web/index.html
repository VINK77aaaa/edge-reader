快捷键与操作

  • 空格 播放 / 暂停（浏览时翻页）
  • ← → 上一句 / 下一句
  • ↑ ↓ PgUp PgDn 滚动
  • T 目录　Ctrl+F 查找
  • Ctrl+= / Ctrl+- 字号
  • F11 全屏　Esc 关闭弹层 / 退出全屏 / 返回
  • 双击句子（或 Alt+单击）从该处朗读
  • 单击句子只定位，不打断当前朗读
